# 주간 보고

1. `list_games` → 게임마다 `weekly_report_preview`(기본 7일).
2. 미해결 상위 이슈 중 `recurrenceOf` 가 있거나 제보가 몰린 것만 `get_issue` 로 확인한다.
3. 게임마다 세 줄로 정리한다.
   - **숫자**: 신규·해결·미해결 (보고 문구 그대로)
   - **눈여겨볼 것**: 재발, 한 증상에 몰린 제보, 결제 관련
   - **다음 주 할 일**: 사람이 정할 것만 (예: 「#12 재발 원인 확인」)
4. 게임이 여럿이면 맨 위에 전체 한 줄(가장 급한 게임과 이유)을 둔다.

서버의 실제 주간 보고는 매주 월요일 9시에 게임별 슬랙 채널로 자동으로 간다. 이 스킬은 그 전에 미리 보거나 다른 기간을 볼 때 쓴다.
